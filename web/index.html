Tuning notes

Start with 1–2 dB changes and Q around 0.7–1 for broad adjustments. Bass weight: 60–150 Hz. Thickness: 200–500 Hz. Voice presence: 1–4 kHz. Brightness: 6–10 kHz.

Boosts need negative preamp gain. Lower it if clips rise. Compare at similar volume: bypass also removes the preamp attenuation. Choose Flat to return to unity gain.
